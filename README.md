# 🚀 Edvexa Server | Node.js & Express REST API

> Built with **Node.js**, **Express**, **MongoDB Atlas Native Driver**, **JWT Auth**, and **Jest / Supertest**.

Please refer to the root [README.md](../README.md) for full project architecture, concurrency design, idempotency mechanics, and API documentation.

### Quick Start
```bash
npm install
npm run seed
npm test
npm start
```
Server runs on [http://localhost:5000](http://localhost:5000)
Health check: [http://localhost:5000/health](http://localhost:5000/health)
